Crossitron is an upside down printer based on a scissor-lift architecture and a completely 3D-printed chassis.


# Features
- Scissor Lift integrated Z-axis, foldable design
- Mostly 3D printed body
- 250mm x 250mm footprint for a 220 x 220 x 150 mm^3 build volume
- Upside-down bed for low center of gravity
- Pre-loaded thrust bearings for smooth z-axis operation
- Twisting 90-degree belt drive
- Positron-style X and Y motion system
